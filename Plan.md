# План: многопользовательская установка на 10+ компьютеров

Каждый пункт делается так, чтобы работали **оба варианта**: по умолчанию — самый
правильный и удобный, а второй включается флагом или в интерактивном меню.

Все операции **идемпотентны** — повторный запуск не ломает уже сделанное
и не создаёт дублей.

---

## Этап 1. Профили аккаунтов  ← делается сейчас

Один компьютер — сколько угодно аккаунтов Unity, каждый в своей папке.

- `data/profiles/<имя>/` — сессия конкретного аккаунта
- `data/profiles.json` — список профилей и профиль по умолчанию
- По умолчанию профиль называется именем пользователя Windows: на школьной
  машине каждый ученик автоматически получает свой, ничего не настраивая
- `--profile <имя>` — работать под конкретным аккаунтом (в том числе общим)
- `--list-profiles` — показать все профили и выйти
- `--set-default-profile <имя>` — сменить профиль по умолчанию
- Старая сессия из `data/unity_session_state.json` переносится в профиль автоматически

## Этап 2. Безопасное хранение входа  ← делается сейчас

- Сессия шифруется средствами Windows (DPAPI) под учётку текущего пользователя.
  С другой машины или из-под другого пользователя файл не читается
- Логин и пароль (если пользователь согласится) кладутся в **Диспетчер учётных
  данных Windows** — их видно в `control /name Microsoft.CredentialManager`
- `--save-password true` — сохранить пароль, вход дальше полностью автоматический
- `--save-password false` — пароль не хранить, только сессия (по умолчанию)
- Без параметра программа спросит один раз после успешного входа
- На Linux и macOS DPAPI нет: файл кладётся с правами `600` и пишется предупреждение

## Этап 3. Синхронизация списков между компьютерами

- `--sources-url <ссылка>` — программа сама скачивает список ассетов по HTTPS
  (raw-ссылка на GitHub, файл в облаке, ссылка на школьный сервер)
- Скачанное кладётся в кэш. Нет интернета — берётся последняя рабочая копия
- Второй вариант остаётся: общая папка или `git pull`, через `--extra-source-file`

## Этап 4. Установка на 10+ компьютеров

- `publish-windows.bat` собирает **один самодостаточный .exe**, .NET на машинах не нужен
- Копируется в сетевую папку или на флешку, запускается двойным щелчком
- Второй вариант остаётся: `git clone` + `dotnet run` для машин, где вы правите код

## Этап 5. Интерактивное меню внутри программы

- Запуск без параметров — программа спрашивает: какой профиль, что делать, какой лимит
- Всё то же самое доступно параметрами, чтобы можно было запускать по расписанию

---

## Про лицензию Unity — важно

Раздавать **платные** ассеты со своего аккаунта ученикам нельзя: лицензия Asset
Store даётся одному человеку. Общий аккаунт на 10+ машинах Unity может
заблокировать вместе со всеми покупками.

Легальный путь, который даёт почти то же самое: у каждого ученика свой бесплатный
аккаунт, программа набирает на него бесплатные ассеты и платные по промокодам из
Telegram. Промокоды — официальные раздачи, ассет остаётся у ученика навсегда.

Профили из Этапа 1 поддерживают оба сценария — какой выбрать, решаете вы.
