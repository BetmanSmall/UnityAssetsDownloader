# Разметка ассетов для каталога

Каталог библиотеки собирает сама программа (`--build-catalog`, пункт K). Ты добавляешь то, чего
нет в данных магазина: суть одной строкой по-русски, для чего ассет годится и подводные камни.
Размечаешь один раз — дальше агенты берут готовое из `categories/*.md`, не тратя токены.

## Где что

- Что размечать: `data/profiles/<профиль>/catalog/ai_todo.jsonl` — строка на ассет без разметки,
  уже в сжатом виде (name, category, tags, rp, unity, pitch, features, desc). На Deck профиль —
  `deck__betmansmall`. Если файла нет или он пуст — спроси, собрать ли каталог (`--build-catalog`).
- Куда писать: `asset_ai_tags.json` в корне репозитория. Номер ассета общий для всех аккаунтов,
  файл едет на сервер через git. Программа его только читает.

## Порядок

1. Возьми пачку: по умолчанию 40 строк сверху (свежие и доступные идут первыми). Если просят
   раздел — отфильтруй: `grep '"category":"3d/characters' ai_todo.jsonl | head -40`.
   Больше 50 за раз не бери: качество падает. ~100 ассетов ≈ 25–30 тыс. токенов.
2. Для каждого ассета составь запись строго по данным строки, ничего не выдумывай:
   - `sum` — до 110 знаков, по-русски, конкретно: что внутри + главное применение.
     Плохо: «Отличный пак для игр». Хорошо: «10 low-poly рыцарей с ригом Mecanim, без анимаций».
   - `use` — 1–4 роли или жанра: «персонаж игрока», «враги», «окружение уровня», «UI меню»,
     «прототип», «мобильная игра», «RPG», «шутер», «редакторный инструмент»…
   - `tags` — 2–6 английских слов в нижнем регистре, которых нет в тегах магазина.
   - `note` — только если есть реальный подвох: «только HDRP», «нужен платный EasyIdleGame»,
     «только анимации, без модели», «под Unity 2018, может не собраться». Нет — не пиши поле.
   Если данных мало (пустые pitch и desc), напиши `sum` по названию и разделу, `use` оставь пустым.
3. Впиши пачку, не трогая уже размеченное:

   ```bash
   python3 - <<'EOF'
   import json
   batch = {  # вставь сюда пачку
       "154271": {"sum": "...", "use": ["..."], "tags": ["..."]},
   }
   path = "asset_ai_tags.json"
   data = json.load(open(path, encoding="utf-8"))
   data.update({k: v for k, v in batch.items() if k not in data})
   json.dump(dict(sorted(data.items(), key=lambda kv: int(kv[0]) if kv[0].isdigit() else 0)),
             open(path, "w", encoding="utf-8"), ensure_ascii=False, indent=1)
   print(len(data), "размечено")
   EOF
   ```

4. Пересобери каталог без браузера и сети — разметка уйдёт в `categories/*.md`, `INDEX.md`,
   `catalog.html`, а из `ai_todo.jsonl` пропадут размеченные:

   ```bash
   dotnet run --project UnityAssetsDownloader/UnityAssetsDownloader.csproj -- \
       --data-dir "$PWD/data" --profile deck__betmansmall --render-catalog --quiet
   ```

5. Скажи, сколько размечено и сколько осталось (`wc -l ai_todo.jsonl`). Закоммитить
   `asset_ai_tags.json` — только если попросят.
